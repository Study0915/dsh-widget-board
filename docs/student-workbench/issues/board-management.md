# 看板标签增加就地重命名与删除入口

状态：本地草稿，未提交。

## 使用场景

在0.1.4桌面端顶部可以新建多个看板，但从标签附近找不到重命名和删除。源码已有设置页管理能力，期望在主要使用位置提供相同动作。

## 方案

标签悬停/聚焦更多菜单及右键菜单，包含重命名、删除；复用现有宿主路由。删除确认包含名称和卡片数量，最后一块删除后仍保留空看板。保留原滑动药丸、字体、令牌和设置页入口。

## 验收目标

- 当前/非当前/最后看板操作正确，失败不丢数据。
- 输入法、键盘、焦点和标签溢出可用。
- Windows标题栏交互和浅深色保持一致。
