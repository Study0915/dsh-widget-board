# 新增校园综合卡片：身份预设、DDL、里程碑与文件交换

状态：本地草稿，未提交。

## 使用场景

学生希望按本科、硕士、博士身份展示近期事项、学业节点和常用入口，并选择学校背景或自定义照片。

## 方案

一种标准campus组件，三身份、通用及北邮/北理/厦大/中南原创视觉预设，独立实例数据，手动事项、CSV/ICS交换、看板运行时提醒。创建后没有虚构日期；默认不连接教务系统。

## 验收目标

- 三身份×四学校和自定义学校可用，风格沿用原令牌。
- 导入有预览、时区、重复决定、额度和原子保存。
- 提醒遵守暂停/恢复和去重，不承诺关闭DSH后台提醒。
- 原创素材与官方参考清楚，图片/事项完整备份。
