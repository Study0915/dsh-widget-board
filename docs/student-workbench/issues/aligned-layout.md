# 增加可选的按行等高排列模式

状态：本地草稿，未提交。

## 使用场景

当前自由布局和紧密整理保留不同纵向位置、尺寸，适合自由摆放；希望同排卡片边缘整齐的用户需要额外排列选择。

## 方案

新增aligned/free模式，新看板默认aligned、旧看板保持free。按阅读顺序逐行放置，同排取最大高度；保留跨列、尺寸档和原间距。两种模式分别保存，切回free恢复旧位置。移动不重挂iframe。

## 验收目标

- 一至四列、跨列、组卡和根字号变化正确。
- 宿主修订号和409继续有效，迁移不重排旧数据。
- 不用free的2rem取整破坏aligned间距。
- 原free算法、计时器、包往返和浅深色不退化。

详细规格：[看板规格](../specs/BOARD.md)。此项作为可选能力，不宣称原作者自由布局设计本身是缺陷。
