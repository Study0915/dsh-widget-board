## 权威与维护

用户当前指令高于本包。行为决策归 `DECISIONS.md`；详细行为归对应规格；跨模块接口归技术契约；验收编号归验收矩阵。任务卡只引用这些权威，不另写一份互相冲突的规则。

本目录用于本地规划和 fork 协作。功能 PR 不自动夹带整套个人工作区约束，公开资料的取舍见 GitHub 流程。

## 完成标准

“文档包完成”只表示本地文件、链接、事实、任务依赖和保护措施已经检查。“功能完成”需要实际代码、真实宿主检查、视觉核对及审阅证据。任何功能目前都不能标为已验收。
