# 页面内卡片创建、编辑与资源规格

## C1. 两种对象

卡片实例拥有 props、data、state 和尺寸；组件类型拥有 manifest、HTML、CSS、JS 和资源。所有按钮、保存接口和测试必须明确修改哪一种对象。

普通模板创建复用对应组件类型，生成新实例。默认不因为用户写了一条笔记就新建一个组件目录。需要源码定制时才创建用户组件类型。

## C2. 页面入口和模板

在加号菜单与组件库头部增加“创建卡片”，打开插件自身范围内的编辑弹窗。

模板顺序：文本笔记、待办清单、常用链接、日期倒计时、图片、校园综合卡、高级组件。校园模板在 T06 加入；T03 不放一个点了无法工作的占位入口。

| 模板 | 基础类型 | 编辑内容 |
|---|---|---|
| 文本笔记 | 优先复用 markdown | 标题、正文 |
| 待办 | todo | 文本、完成状态、项目顺序 |
| 链接 | links | 标题、http/https 地址、小图标 |
| 日期倒计时 | 新增 countdown | 日期类型、时区、名称、说明 |
| 图片 | image | 本地图片、alt、caption、焦点位置 |
| 校园 | campus | 学校、身份、事项与入口 |

复用时先核对原组件现有 data/state 职责，不把用户已有数据换成另一种含义。必要的新 schema 兼容原字段。

## C3. 表单与保存

表单支持：string、multiline、number、boolean、enum、object 分组、array 项目、日期、时间、URL 和本地图片引用。

- label、hint、默认值、必填和限制取 manifest/schema；不写另一套硬编码必填规则。
- 以 object/array 为递归边界，编辑器最多展开四层；更深结构提供显式 JSON 编辑，不假装能编辑。
- array 支持添加、删除、上下移动，稳定 item id 保持焦点。
- 不支持的联合 schema 提供可见 JSON 编辑方式和 schema 错误位置。
- 普通字段和凭据继续分清：凭据走既有凭据服务，不进入 props、data、state、草稿或导出。
- 表单草稿仅在点击保存后进入正式实例。
- 创建时校验类型、props、初始 data/state、尺寸和总字节额度，一次创建实例；失败不残留空卡片。
- 编辑读取 revision，提交 expectedRevision；409 保留本地草稿并展示重新读取/另存入口。
- 所有 schema 校验复用既有 Ajv 与共享校验入口。

卡片内容保存是人工操作的宿主路由，不能让沙箱借同一接口覆盖任意实例。沿用宿主请求栅栏；身份由路由上下文确认。

## C4. 高级源码

CodeMirror 6 在进入高级模式时按需加载，提供 manifest、HTML、CSS、JS 标签、行号、错误位置、搜索和缩进。外观读取原令牌，不加载另一套配色。

其他受支持的资源以文件列表呈现。必需文件为 widget.json、index.html、style.css；main.js 和 samples.json 可选。成熟格式使用已有库。

来源规则：

1. builtin、plugin、example（如果上游以后加入）均作为只读源。
2. 编辑这些来源时创建唯一用户 id，默认 `user-<slug>-<短随机标识>`；manifest.id 与目录名一致。
3. 编辑已有 user 类型默认另存并只应用当前卡片。
4. 明确选择“更新全部实例”时，显示被影响的看板和实例数量，并提交 expectedHash。
5. 并发类型变更返回 409；禁止依靠 replace=true 绕过来源和版本核对。
6. 组件更新后按既有 hash 策略重读授权；不迁移旧 hash 的 grant。

只应用当前卡片时保留实例 id、内容和布局；先按新 schema 校验现有内容，不能静默清空不兼容字段。需要用户明确确认字段调整，或取消应用。

## C5. 草稿

- 独立目录：`$DSH_HOME/widget-board/drafts/`。
- 草稿含 draftId、目标实例/类型、基础 hash/revision、文件及表单值、更新时间。
- 明确排除凭据值。
- 关闭脏编辑器选择保存草稿、放弃或继续编辑。
- 成功正式保存后可删除本次草稿；保存失败保留。
- 不自动启动草稿代码；用户恢复后才进入预览。
- 单草稿按组件文件包上限约束；最多二十份，满额明确提示用户管理，不静默删除旧草稿。

## C6. 预览

预览请求先经过正式 manifest/路径/文件校验；使用同一 buildDocument、运行时和 iframe 策略。

- 预览文件只存独立内存会话，不写正式 widgets、versions、boards 或 grants。
- 返回不可猜测 previewId；十分钟过期；关闭释放；同时最多四个会话。
- 预览 props/data/state 大小分别遵守对应桥与状态限制，不能把整个组件文件塞进握手。
- 预览状态变更只写预览会话；通知不进入正式未读列表；外部动作、HTTP、凭据和正式媒体读取拒绝。
- 用户本次选择的图片以受限预览附件载入；只读当前 previewId 的附件。
- 尺寸切换只改变预览视口。提供浅深色、窄/常规/宽、矮/常规/高和当前尺寸。
- 防抖 300ms 后重建预览；显式运行按钮可立即刷新。
- 退出、异常及组件替换时释放端口、计时器和对象地址。

## C7. 本地图片

实际处理与读取协议见技术契约。编辑器只负责选取、尺寸体积预检、裁切/焦点、预览和绑定。

支持 PNG/JPEG/WebP；单原图 ≤10MiB、最长边 ≤8192px。转为静态 WebP，去元数据；背景最长边 ≤1600px 且 ≤2MiB，图标最长边 ≤256px 且 ≤128KiB。格式校验依据真实文件签名和解码结果，不只看扩展名。

转换失败、动画图片、不支持的格式和超限显示明确错误。上传 SVG 暂不支持；源码资源包中的 SVG 仍按原组件资源规则处理，两条入口不能混淆。

## C8. 导出与失败

- `.dshw` 导出组件类型源码及其类型资源；实例独有的事项和图片通过 `.dshboard` 保存。
- 保存为可分享模板时先选择是否包含实例样例，不默认把用户事项写进 samples。
- 资源与草稿均不能改变旧版组件包含义。
- 网络中断、宿主不可用、校验失败、冲突和磁盘写入失败分别反馈；输入继续存在。
- 卡片从其他窗口被删除后，编辑器提示目标不存在，允许把草稿另存为新卡片。

## C9. 回归依据

验收编号 C01—C17、M01—M12。至少真实创建一张用户组件、另存 builtin、尝试覆盖只读类型、制造 expectedHash 冲突、恢复草稿、导出导入含媒体看板，并检查无 CSP 放宽。
