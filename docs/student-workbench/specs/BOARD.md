# 看板管理与整齐排列规格

权威决定：U01、U02。基线：自由位置、设置页管理、多看板宿主权威保持有效。本文件新增的界面与排列规则需要在实施时更新相关原仓库决策。

## B1. 标签管理

### 正常路径

1. 标签文字继续承担切换职责。
2. 每块标签对应独立的更多按钮，悬停或 focus-within 时出现；键盘聚焦时始终可见。
3. 更多按钮及标签右键调用同一个管理菜单，菜单记录目标 boardId。
4. 非当前标签打开菜单时不自动切换看板。
5. 关闭菜单后焦点回到触发按钮；Escape 关闭；外部点击关闭。
6. 菜单提供重命名与删除；不在此任务增加复制、排序、分组等能力。

tablist 中保持合法的 tab 结构，菜单按钮使用独立可聚焦控件，不能把 button 嵌进 button。标签用稳定 id；重命名只改变文字和宽度。

### 重命名

- 弹窗只盖插件自己的内容区域；视觉复用现有 editor 弹窗。
- 输入预填当前名，trim 后为空则就近显示错误。
- 名称上限沿用已有接口规则；若上游确实没有长度限制，新增统一的 80 个 Unicode 字符限制，并在客户端/宿主/测试一起定义。
- Enter 保存、Escape 取消；中文输入法组合期间 Enter 不触发保存。
- 保存中禁用重复提交；失败保留文字；成功更新快照并重新测量药丸与标题栏容纳空间。
- 重名允许，继续使用 boardId 区分；不引入名称唯一性约束。

### 删除

确认弹窗显示看板标题、排列单元数量和卡片实例数量；组卡按一格、两实例解释。文案说明删除该看板的卡片及其保存内容。

- 删除操作只调用既有 removeBoard；删除后的活动看板由现有 Workspace 决定。
- 删除非当前看板不额外 activate；当前看板删除后以宿主结果为准。
- 最后一块删除后沿用现有创建空看板的逻辑；新的空看板使用 aligned 默认值。
- 点击确认后出现忙碌状态，成功后重取快照；失败保持原界面并显示错误。
- 删除不撤销用户组件类型，不删除其他看板，也不直接清理版本 blob。
- 不新增“假撤销”按钮：未提供可靠的完整恢复能力时只提供确认删除。

### 桌面标题栏与溢出

复用 titlebarSeat 判断；新增按钮参与宽度测量。菜单热点明确为不可拖窗区域，空白标题栏仍可拖动。放不下时回到页面顶部；页面顶部横向滚动并确保活动标签可见。不改宿主窗口控制按钮及 DOM。

## B2. 两种排列偏好

详细数据形状见技术契约。本规格只决定行为。

- 旧版看板读取为 free，不调整原实例 layout。
- 新建看板与首次创建的默认看板使用 aligned；已存在的画廊不自动改变。
- 第一次切到 aligned，使用当前屏幕上已经解决碰撞的布局按 y、x、原输入索引稳定排序。
- 再切换时恢复已保存的 aligned 偏好，不每次按 free 重新生成。
- 切到 free 恢复独立保存的自由位置。
- 两种模式共用卡片实例、内容和状态，不复制卡片。

## B3. 按行模型

输入：稳定顺序的排列单元，期望宽高，当前 metrics，组件最小尺寸。

输出：每个排列单元的像素盒子、总高度；输出是派生显示结果，不覆盖 free layout。

步骤：

1. 列数和列宽继续由现有 gridMetrics 得出。
2. 显示宽度为期望跨列数受当前列数限制后的值，同时满足当前能满足的 minBox。
3. 依次装入当前行；剩余空间不足时开启下一行，禁止回填更前一行的空位。
4. 行高为该行所有期望高度、minBox 所需高度的最大合法高度档。
5. 该行所有格子的 top、height 相同。
6. 第一行 top=0；后续行 top=上一行 top+height+metrics.gap。
7. 水平位置使用列宽和 metrics.gap；高度保持现有档位，纵向位置直接使用派生值。
8. 不调用 snapCardY/ceilCardY 处理 aligned 的行坐标；保留自由模型原行为。

例：三列时，A 占两列高 18rem，B 占一列高 14rem，两者同排高 18rem；C、D 下一行高 14rem。下一行与上一行间隔 0.75rem。

四列且宽度依次为 2、1、2 时，第一行放前两张并留一列，第二行放第三张。阅读顺序保持，不把第三张插回上一行。

## B4. 手势

### 拖动

在 aligned 中拖动是调整顺序。按指针落入的派生行和格子确定插入位置，显示原有风格的虚影；松手只提交新的 order。Escape 或丢失指针时取消未提交草稿。没有位移的按下/松开不提交。

卡片 key 和父容器保持，视觉跟手使用已有外壳；禁止通过移动 iframe DOM 实现排序。

### 缩放

- 横向仍按列吸附，保存期望 w。
- 纵向调整整行：把手势开始时同一行的所有单元期望高度写成新的合法高度档，并至少满足这一行最大的 minBox。
- 一次手势是一份原子排列提交。
- 组卡尺寸取两个面当前组件 minBox 的并集。
- 单张卡在窄屏受限显示时，不能把暂时截断的 w 写成新的期望宽度。

### 并发

提交携带 expectedLayoutRevision。宿主验证后原子写入并递增 revision/layoutRevision；过期返回 409 与快照。失败清除草稿、恢复宿主确认状态，不能留下假成功位置。

## B5. 增删与整理

- 新卡片加入 aligned 顺序末尾，free 位置仍通过现有默认放置逻辑产生。
- 移除卡片或组时同步移除两种偏好中的引用。
- aligned 的“整理”只重新解析当前顺序，不擅自改变宽度或次序；界面说明当前已经按行排列。
- free 保留原“紧密整理”。排列模式选择与原整理命令分开命名，避免用户误解。
- 组件不可用仍占原格子，保留可移除的占位说明。

## B6. 回归依据
