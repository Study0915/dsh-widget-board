# 文件交换、日期与提醒规格

## I1. 日期语义

使用两个互斥形状：

```ts
type Due =
  | { kind: 'date'; date: string; timeZone: string }
  | { kind: 'instant'; at: string; timeZone: string }
```

date 是有效 YYYY-MM-DD 日历日期；at 是带 Z 的 ISO UTC 时刻；timeZone 是有效 IANA 名称。默认 Asia/Shanghai。日期转换使用成熟时间库（实现时选定并锁定 Luxon，复用其 IANA 支持），不手写偏移量算法。

全天项目在该时区次日00:00开始超期；日期差按日历计算。精确项目在 at 时刻超期；界面同时显示日期、时刻和时区。非法日期、DST 不存在的时间拒绝；DST 重复时间要求用户选择明确偏移，不静默选择。

## I2. 导入通用流程

选择文件→解析→字段/时区配置→逐行预览→重复项决定→容量校验→一次保存。所有正式写入等到用户点击确认。

- 文件上限2MiB；解析后最多10000个候选，超过即报错。
- 预览同时列出有效、无效、重复和容量超限，不只显示成功条数。
- 可以取消选择有错误的行，不能静默丢弃；选中行必须全部有效。
- 原子保存携带 expectedRevision；409 保留预览，重新匹配目标现有项目后由用户再次确认。
- 单卡总数和64KiB体积均满足才提交。不能自动删旧项或截断新项。
- URL、说明只作为文本处理，不插入未经净化的HTML；文件内说明不作为执行指令。

重复键：优先来源UID＋发生时间；CSV无UID时使用kind、规范化title、due、timeZone、url的确定性摘要。预览默认跳过重复项；提供更新或保留两条。更新显示差异，保留现有本地id，不默认重置完成状态或提醒记录。保留两条生成新本地id。

## I3. CSV

Papa Parse 处理读取和导出。固定导出表头：

`kind,title,category,due,dateOnly,timeZone,status,url,note,uid`

支持中文表头映射，例如“标题→title”“截止日期→due”“时区→timeZone”。必须由用户确认映射，不按列号猜。

- UTF-8，可含BOM；支持引号、逗号和换行。
- title和due必需；kind默认deadline；status默认todo；其他可空。
- dateOnly 为true时due只接受日期；false时必须是含偏移的时间或在预览阶段结合指定时区解析的本地时间。
- 标准模板中timeZone明确写Asia/Shanghai，避免无时区误解。
- 导出逃逸公式字段，不能把用户文本当电子表格公式。
- 导出默认当前筛选范围，确认框明确总数；允许包含已完成/取消项目。

## I4. ICS

ical.js负责标准解析、RRULE、RDATE、EXDATE和RECURRENCE-ID。禁止用split行或正则自行替代日历解析。

映射：

| 来源 | 目标 |
|---|---|
| VEVENT DTSTART | 截止日期或时刻；DTEND只作为说明保存，不误当作开始截止 |
| VTODO DUE | 截止；没有DUE的条目进入错误预览 |
| SUMMARY/DESCRIPTION/URL | title/note/url，超过限制显示可编辑错误 |
| UID＋发生时间 | 来源标识 |
| VTODO STATUS=COMPLETED | done |
| STATUS=CANCELLED | cancelled |
| 其他有效条目 | todo，kind默认deadline，允许预览改为milestone |

时区：UTC直接解析；VTIMEZONE按库注册；浮动时间要求确认目标时区。TZID没有可解析定义时可通过已安装时间库的IANA数据解释；无法解释则显示错误并要求指定。绝不把未知时区当本机时区。

重复规则默认展开从今天到一年后，日期范围可以修改。逐次展开有10000次计算上限、最终卡片100条上限；超限终止并提示缩小范围。保留取消例外和变更例外，不能只展开RRULE忽略其余定义。

导出：VEVENT，稳定UID，精确时刻导出UTC DTSTART且不虚构时长；全天导出DATE DTSTART与次日DATE DTEND。分类/状态/kind/timeZone用X-DSH扩展字段保留。再次导入本插件导出的文件时优先解释这些受支持扩展；第三方日历可能不显示扩展，完整备份使用看板包。

## I5. 提醒节点

默认提前一天和到期提醒：

- 精确时刻：at-24小时、at。
- 全天日期：前一天09:00、当天09:00（卡片时区）。
- 看板打开且卡片挂载时立即检查，未暂停期间每分钟检查。
- 切离看板或onPause(true)停止定时器，恢复后补查；关闭DSH后无检查。
- 用户可关闭提醒；提前量只提供0小时、1小时、24小时、72小时四个选项，默认24小时，避免任意复杂规则。
- done/cancelled不提醒；修改截止时间后按新时间版本重新计算。

## I6. 去重与未读提示

key由本地事项id、截止内容版本和提醒节点组成。已发送节点存入实例状态；清理已删除事项和旧截止版本的记录，控制体积。

同一轮同时命中多个节点时，只发一条当前说明并标记所有已到节点，避免打开看板连发两条。多事项到期合并为一条摘要，点击现有看板入口后能查看事项。

通知进入现有notificationStore，生命周期仍是当前页面。已读语义沿用原插件，不新增持久通知中心。提醒记录持久化失败时显示错误并停止该轮通知，避免反复发送。多窗口各自显示允许重复，不承诺跨窗口唯一。

## I7. 样例和测试

提供UTF-8 CSV标准模板、带全天/UTC/浮动时间/VTIMEZONE/重复例外的ICS夹具，全部标为演示数据。固定时钟和时区用于纯逻辑测试；真实宿主以用户能观察的状态验收，不用长时间sleep等待一天。

覆盖 I01—I15、N01—N08。截止时刻边界、跨年、闰日、夏令时切换和相同UID例外必须有断言。
