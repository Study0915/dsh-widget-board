# 与原作者一致的视觉规格

## 1. 参考优先级

原仓库tokens与组件套件→当前基线的card/editor/tabs/library→原仓库浅深色截图→用户提供的实际截图。截图中的橙色来自宿主主题，不能写死为插件唯一品牌色。

本地参考：`docs/images/board-light.png`、`docs/images/board-dark.png`。用户截图副本只保存在`.debug/references`，不自动提交公开仓库。

## 2. 固定设计语言

| 元素 | 实现约束 | 审阅方法 |
|---|---|---|
| 字体 | --dsw-font-family，经原token进入iframe | computed style与原卡一致 |
| 圆角 | 原card=24px，裁剪继续使用原CardShell | 浅深色四角无白边 |
| 间距 | xs4/sm8/md12/lg16/xl24/2xl32 | 主要内边距和行距与原卡对照 |
| 字号 | caption12/body14/title16/heading20/display40 | 保持标题/正文/说明层次 |
| 表面 | bg、surface、border、fg、muted语义别名 | 浅深色切换即时有效 |
| 强调 | 宿主accent/on-accent | 不复制固定橙色或紫色 |
| 阴影 | 复用board/card/editor已有规则 | 相邻原卡与新卡深浅接近 |
| 背板 | 原点阵密度和对比 | 新弹窗不换整页背景 |
| 图标 | 16px常规、现有12px小控件、约1.4px圆线 | 不混入emoji作主要操作图标 |
| 动效 | 既有150/250ms等token和原曲线 | prefers-reduced-motion静置 |

圆角、阴影和字体不要在校园组件里再定义一套字面值。必要的新语义token需要单独说明，默认本项目无需修改tokens.json。

## 3. 新控件对应原控件

- 管理菜单：参考dock/library的小型浮层，紧凑文字和hover背景。
- 删除/重命名弹窗：参考editor题头、表面、按钮及页脚；危险操作采用既有语义色并附文字。
- 创建器：原editor浮层延伸，左侧配置右侧预览；窄窗口改为分段切换，不能横向溢出。
- 高级编辑器：CodeMirror继承原字体色/表面，代码字体使用宿主已有等宽族，不增加字体下载。
- 校园卡：参考todo、links、calendar的密度，装饰仅在上部视觉带。
- 所有外壳增加语义data-dsh-widget-*属性；选择器限定本插件根范围。

## 4. 学校预设设计

| 学校 | 原创图案 | UI调色方向 | 来源 |
|---|---|---|---|
| 北邮 | 点划摩斯路与钟形几何 | 通信蓝、淡灰点线 | https://vi.bupt.edu.cn/xywm/tsdb.htm |
| 北理 | 主楼轮廓与树影 | 克制校园绿 | https://www.bit.edu.cn/gbxxgk/dqgz_sjb/a173964.htm |
| 厦大 | 嘉庚式屋顶、海滨弧线 | 普蓝方向、少量暖屋顶线 | https://news.xmu.edu.cn/info/1003/22405.htm |
| 中南 | 岳麓山校区图书馆、山线 | 中南蓝方向 | https://www.csu.edu.cn/zjzn/xxbs/bzs.htm |

图案不是官方标志；用简化轮廓和局部色传达校园特色。每个原创SVG保留viewBox和语义分组，默认正文区不铺图。浅深色分别调整装饰透明度，操作按钮依然跟随宿主accent。

通用主题为书页、树影、钟面三套原创图案。自定义照片通过背景焦点、浓淡和主题遮罩适配，不把所有文字直接放在照片上。

素材登记记录文件名、原创/外部来源、参考链接、作者、使用说明和核查日期。外部素材不能仅凭“官网可下载”就当成可随MIT包分发；没有明确分发依据时保留原创装饰方案。

## 5. 截图矩阵

同一份示例数据，在1920×1080、1440×900、1024×768和单列容器分别检查。CSS viewport、zoom、DPR一致后再比较，不拿用户物理截图直接做像素阈值断言。

每项视觉任务至少保存：

1. 原版同位置基线。
2. 修改后原生浅色、深色。
3. dsh-claude-style 0.17.0兼容主题的浅色、深色（版本变化时记录实际版本）。
4. 最窄和最矮支持尺寸。
5. 键盘焦点和打开菜单/弹窗状态。

截图存`.debug/evidence/<任务>/`，正式审阅记录写路径和观察结论。人工核对同排边缘的测量允许1 CSS px差异；自动模型测试断言几何关系和确定性，遵循原项目不做脆弱像素截图比较的方向。

## 6. 风格审阅判据

通过：与原卡并排时字体、留白、圆角、边框、操作密度统一；学校图案可识别但不压过任务信息；浅深色的正文和状态清楚；没有横向溢出或被裁剪的按钮。

不通过：另加字体、全局固定配色、大片玻璃渐变、重阴影、多层容器套框、标题尺寸突兀、把源码字段暴露给普通用户流程、只检查浅色、只给截图却未打开核对。
